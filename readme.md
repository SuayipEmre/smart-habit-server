# 🧠 SmartHabit - Backend (Node.js + Express + MongoDB)

SmartHabit is a **habit tracking application** that helps users build routines, set reminders, and monitor their daily progress.  
This repository contains the **backend (server)** part of the project.

---

## 🚀 Features

- 🔐 **JWT Authentication & Refresh Token** for secure session management  
- 🧩 **RESTful API architecture** built with Express.js  
- 🧠 **MongoDB + Mongoose** for flexible data modeling  
- ⏰ **Cron Jobs** to automatically reset daily habits  
- ✉️ **Email Notifications** for reminders and updates  
- ⚙️ **sendResponse utility** for consistent API responses  
- 🧱 **Modular structure** with routes, controllers, services, and middlewares  
- 📦 **Environment-based config** using dotenv  

---

## 🛠️ Tech Stack

| Technology | Description |
|-------------|--------------|
| **Node.js** | JavaScript runtime environment |
| **Express.js** | Web framework for REST APIs |
| **MongoDB + Mongoose** | NoSQL database and ODM |
| **JSON Web Token (JWT)** | Authentication and session handling |
| **Nodemailer** | Email sending service |
| **Node-Cron** | Task scheduling (habit resets, etc.) |
| **dotenv** | Environment variable management |
